# HSPICE 指令集


## 要求


### 存储

1. 地址空间为 2^8 （8 bit 地址）

2. 每个地址可以存取多少bit  8 bit

### 处理单元

1. 处理位宽 8bit

2. 指令集

    1. 9bit 
    2. 格式:
        1. 8个Opcode，3bit
        2. 4个寄存器，共2bit 表示

    3. Opcode

        1. ADD  000

        2. SUB  001

        3. AND  010

        4. NOR  011

        5. NOT  100

        6. LOAD 101

        7. STORE 110

    4. 指令位域分配

        | 位域范围 | 字段含义       |
        |----------|----------------|
        | 0-2      | 操作码 (opcode) |
        | 3-4      | 源寄存器1      |
        | 5-6      | 源寄存器2      |
        | 7-8      | 目标寄存器     |
    
    5. 指令列表

        |        | 0-2    | 3-4      | 5-6       | 7-8       |                       |
        |--------|--------|-----------|-----------|------------|------------------------|
        | 指令名 | 操作码 | 源操作数1 | 源操作数2 | 目标操作数 | 备注                   |
        | ADD    | 000      | 寄存器    | 寄存器    | 寄存器     | 算术加法               |
        | SUB    | 001      | 寄存器    | 寄存器    | 寄存器     | 算术减法               |
        | AND    | 010      | 寄存器    | 寄存器    | 寄存器     | 逻辑与                 |
        | NOR    | 011      | 寄存器    | 寄存器    | 寄存器     | 逻辑或非               |
        | NOT    | 100      | -         | -    | 寄存器     | 单操作数逻辑非         |
        | LOAD   | 101      | 寄存器    | -    | 寄存器     | 内存加载（基址+偏移）  |
        | STORE  | 110      | 寄存器    | -    | 寄存器     | 内存存储（基址+偏移）  |
