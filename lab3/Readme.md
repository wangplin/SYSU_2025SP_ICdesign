# VLSI课程设计：基于HSPICE的8位MCU晶体管级设计与优化  

## 设计目标  
设计并仿真一个8位低功耗MCU，完全基于晶体管级CMOS电路，使用HSPICE完成所有模块设计与验证。具体要求如下：  
1. 功能模块：  
   - 数据通路（ALU、寄存器文件、程序计数器）  
   - 控制单元（指令译码器、多周期状态机）  
   - 存储单元（8×8 SRAM阵列）  
2. 性能指标：  
   - 主频 ≥ 20MHz（TT工艺角）  
   - 单指令动态功耗 ≤ 3μW @1MHz  
   - 关键路径延时 ≤ 10ns  

## 设计任务分解  

### 1. 数据通路设计  

#### 1.1 ALU模块  
- **功能**：支持8位加、减、与、或运算。  
- **设计要求**：  
  - 使用传输门逻辑或动态CMOS设计加法器，对比行波进位与超前进位结构的功耗-延时积（PDP）。  
  - 提供关键路径（如进位链）的瞬态仿真波形。  

#### 1.2 寄存器文件  
- **功能**：4×8位寄存器，支持双端口读写。  
- **设计要求**：  
  - 基于D触发器和三态门设计，仿真读写冲突场景。  
  - 添加门控时钟电路，优化动态功耗。  

### 2. 控制单元设计  

#### 2.1 指令译码器  
- **功能**：解析3位Opcode，生成8条指令控制信号（如`ADD_en`, `LOAD_en`）。  
- **设计要求**：  
  - 使用**CMOS与非门和反相器**构建3-8译码器。  
  - 仿真验证`ADD`（Opcode=000）和`LOAD`（Opcode=100）指令的译码信号。  

#### 2.2 多周期状态机  
- **功能**：实现5状态流水线（Fetch/Decode/Execute/Memory/WriteBack）。  
- **设计要求**：  
  - 使用D触发器级联实现状态寄存器。  
  - 仿真状态转移过程（如Fetch→Decode→Execute）。  

### 3. 存储单元设计  

#### 3.1 6T SRAM单元  
- **设计要求**：  
  - 设计单6T存储单元，分析静态噪声容限（SNM）。  
  - 仿真读写操作波形，测量存取时间和保持功耗。  

#### 3.2 SRAM阵列扩展  
- **设计要求**：  
  - 设计8×8存储阵列，含行/列译码器和灵敏放大器。  
  - 仿真`LOAD`指令从地址0x04读取数据的完整路径。  

### 4. 全局优化与验证  
- **时钟树设计**：插入缓冲器平衡时钟偏移，仿真不同工艺角（TT/FF/SS）下的时钟延迟。  
- **功耗优化**：对比门控时钟优化前后的动态功耗。  

## 设计提示与常见问题  

### 1. 指令译码器设计提示  
- **毛刺消除**：在译码器输出端添加锁存器（Latch）或调整晶体管尺寸。  
- **控制信号组合**：使用与门结合译码器输出和状态信号（如`ADD_en = Y0 AND Execute_phase`）。  

### 2. 状态机设计提示  
- **次态逻辑实现**：  
  - 组合逻辑示例：`D3 = Q2 AND LOAD_en`（从Execute→Memory）。  
  - 晶体管级实现需用与非门/或非门构建逻辑表达式。  
- **时序收敛**：若次态逻辑延迟超过时钟周期，插入缓冲器优化关键路径。
